# README

This repository contains the source code and experimental results used in the
bachelor thesis **"Merging Differently Sized Neural Networks"**.

## Repository Structure

```text
.
├── data/
│   └── Training and test data for the datasets used in the experiments.
│
├── notebooks/
│   ├── analysis/
│   │   └── Jupyter notebooks used to generate the figures
│   │       presented in the thesis.
│   │
│   └── Fisher_approximation_experiments/
│       └── Jupyter notebooks containing the experiments,
│           organized into their respective subcategories.
│
├── results/
│   └── Results generated by the experiments, stored as
│       pickle (.pkl) files.
│
└── src/
    ├── merging/
    │   └── Implementations of the neural network merging
    │       methods used in the thesis.
    │
    ├── model/
    │   └── Infrastructure for setting up and running
    │       the individual experiments.
    │
    ├── tables/
    │   └── Source code used to generate the figures
    │       and tables presented in the thesis.
    │
    └── utils/
        └── General-purpose utility modules used throughout
            the project.
